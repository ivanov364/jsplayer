# Music Player (jsplayer)

A desktop music player simulation built with **JavaScript** and **Electron**. This project models a hierarchical playlist system utilizing a **Circular Doubly Linked List** combined with an inner **Doubly Linked List** and a custom **Queue** for playback management.

## ⚙️ Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v22 or higher recommended)
* npm (comes with Node.js)
* GNU/Linux environment (configured for X11)

### Installation & Running

1. Clone the repository:
```bash
git clone https://github.com/ivanov364/jsplayer.git
cd jsplayer

```


2. Install dependencies:
```bash
npm install
```


3. Start the Electron application:
```bash
npm run start
```
